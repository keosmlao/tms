# 📝 WI — ຄຳແນະນຳການເຮັດວຽກ 1-2-3 (Work Instructions)

**Work Instructions (WI).** ບັດຂັ້ນຕອນການເຮັດວຽກ 1-2-3 ແຍກຕາມແຕ່ລະວຽກ ທີ່ສາມາດປະຕິບັດຕາມໄດ້ທັນທີ.

---

## 🗂️ ໝວດ A: ພະນັກງານ Office / Dispatch

### 📌 WI-A1: ຈັດຖ້ຽວບິນ (Assign Date & Route)
1. ເປີດເມນູ <span class="path">ຂົນສົ່ງ › ລໍຖ້າຈັດຖ້ຽວ</span>
2. ໝາຍເລືອກບິນ (ເລືອກໄດ້ຫຼາຍໃບ)
3. ກຳນົດ **ວັນຈັດສົ່ງ** · **ຮອບການຈັດສົ່ງ** · **ເສັ້ນທາງ**
4. ກົດ **ບັນທຶກ** ➔ ບິນຈະຍ້າຍໄປໜ້າ <span class="path">ບິນລໍຕາມເສັ້ນທາງ</span>

---

### 📌 WI-A2: ສ້າງໃບງານ (Create Job Order)
1. ເປີດເມນູ <span class="path">ຂົນສົ່ງ › ບິນລໍຕາມເສັ້ນທາງ</span>
2. ເລືອກກຸ່ມບິນຕາມເສັ້ນທາງ ➔ ກົດ **ສ້າງໃບງານ**
3. ເລືອກ **ລົດ** + **ຄົນຂັບລົດ** (ກວດສອບນ້ຳໜັກບັນຈຸບໍ່ໃຫ້ເກີນ)
4. ກົດ **ສົ່ງອະນຸມັດ** ➔ ໃບງານຈະຍ້າຍໄປໜ້າ <span class="path">ໃບງານ / ລໍຖ້າອະນຸມັດ</span>

---

### 📌 WI-A3: ກວດຮັບ & ປິດງານ (Audit & Close Job)
1. ເປີດເມນູ <span class="path">ຂົນສົ່ງ › ຄົນຂັບປິດງານ</span>
2. ກວດສອບຮູບຫຼັກຖານການສົ່ງ + ຈຳນວນສິນຄ້າ ຕໍ່ 1 ບິນ
3. **ຖ້າຖືກຕ້ອງຄົບຖ້ວນ:** ກົດ **ປິດສຳເລັດ** ➔ ໃບງານຍ້າຍໄປ *ປິດສຳເລັດແລ້ວ*
4. **ຖ້າຂາດ/ຜິດ/ກົດຜິດ:** ກົດ **ຕີກັບ (Revert)** ➔ ໃສ່ເຫດຜົນ ➔ ຍ້ອນກັບໃຫ້ຄົນຂັບແກ້ໄຂ

---

### 📌 WI-A4: ແຍກບິນຕາມສາຂາ (Split Bill by Branch)
**ອັດຕະໂນມັດ (ຄ່າຕັ້ງຕົ້ນ):** ບິນທີ່ເບີກຈາກຫຼາຍສາງ ແລະ ແຕ່ລະສາງຢູ່ຄົນລະສາຂາຂົນສົ່ງ (ເຊັ່ນ ສາງຂົວຫຼວງ + ສາງດອນຕິ້ວ)
ລະບົບຈະແຍກໃຫ້ເອງທັນທີທີ່ບິນເຂົ້າຄິວ *ລໍຖ້າຈັດຖ້ຽວ*:
- ສາຂາເຈົ້າຂອງບິນ (transport ຂອງບິນ) ເຫັນບິນຕົ້ນສະບັບ ແຕ່ເຫຼືອສະເພາະສິນຄ້າໃນສາງຂອງຕົນ — ມີປ້າຍ **🔀 ແຍກໄປ …**
- ສາຂາອື່ນເຫັນ **ບິນຍ່ອຍ `ເລກບິນ#02-xxxx`** (ປ້າຍ **🔀 ຈາກ …**) ໃນຄິວຂອງຕົນ ➔ ນັດວັນ / ຮອບ / ເສັ້ນທາງ ແລ້ວຈັດຖ້ຽວເອງໄດ້ເລີຍ ບໍ່ຕ້ອງລໍຖ້າສາຂາເຈົ້າຂອງ
- ຖ້າຢາກໃຫ້ສາຂາເຈົ້າຂອງສົ່ງທັງໝົດແທນ: ຢູ່ແຖວບິນຍ່ອຍ ກົດ **ຄືນໃຫ້ບິນແມ່** ➔ ສິນຄ້າກັບຄືນບິນຕົ້ນສະບັບ (ລະບົບຈະບໍ່ແຍກຄືນອີກ)

**ດ້ວຍມື (ກໍລະນີພິເສດ, ເລືອກສາຂາເອງ):**
1. ຢູ່ໜ້າ <span class="path">ຂົນສົ່ງ › ຈັດຖ້ຽວ</span> ເປີດບິນທີ່ມີຫຼາຍສາງ
2. ກົດ **ຈັດຖ້ຽວທີ່ເຫຼືອຕາມສາຂາ**
3. ເລືອກລາຍການສິນຄ້າ ➔ ລະບຸສາຂາປາຍທາງ + ວັນ + ຮອບ
4. ກົດ **ບັນທຶກ** ➔ ລະບົບຈະສ້າງບິນຍ່ອຍແຍກຕາມສາຂາ

---

### 📌 WI-A8: ຮັບເງິນ COD ຈາກຄົນຂັບ (Cash Handover)
1. ເປີດ <span class="path">ຂົນສົ່ງ › ກະທົບຍອດເງິນ COD</span>
2. ຄ່າຕັ້ງຕົ້ນສະແດງ **ສະເພາະຖ້ຽວທີ່ຍັງບໍ່ໄດ້ມອບເງິນ** ຂອງມື້ນີ້ (ປ່ຽນຊ່ວງວັນທີໄດ້)
3. ເບິ່ງແຖວຖ້ຽວ: **ເງິນສົດ** = ຈຳນວນທີ່ຄົນຂັບຕ້ອງມອບ
4. ນັບເງິນຕໍ່ໜ້າຄົນຂັບ ➔ ກົດ **ຮັບເງິນ** ➔ ປ້ອນຍອດທີ່ນັບໄດ້ຈິງ ➔ **ຢືນຢັນ**
   - ຖ້າຍອດບໍ່ກົງກັບລະບົບ ➔ **ບັງຄັບໃສ່ເຫດຜົນ**
5. ກົດບໍ່ໄດ້ ຖ້າຍັງມີບິນທີ່ຄົນຂັບບໍ່ທັນບັນທຶກການເກັບເງິນ (ຈະຂຶ້ນ *ຍັງສົ່ງບໍ່ຄົບ*)
6. ມອບຜິດ ➔ ກົດ **ຍົກເລີກ** ແລ້ວມອບໃໝ່

ພາບລວມຕໍ່ຄົນຂັບ ເບິ່ງທີ່ <span class="path">ລາຍງານ › COD ຕາມຄົນຂັບ</span>.

---

### 📌 WI-A5: ປັກໝຸດ/ແກ້ໄຂຕຳແໜ່ງ (Edit Location / Pin Map)
1. ຖ້າບິນບໍ່ມີພິກັດ Lat/Lng ຫຼື ພິກັດຜິດ
2. ກົດ **ແກ້ໄຂຕຳແໜ່ງ (Edit Location)** ຢູ່ໜ້າບິນ
3. ຄົ້ນຫາສະຖານທີ່ ຫຼື ຍ້າຍໝຸດເທິງ Google Maps ➔ ກົດ **ບັນທຶກ**

---

### 📌 WI-A6: ຈັດການບິນສົ່ງຕໍ່ສາຂາ (Branch Forwarding)
1. ເມື່ອມີບິນສົ່ງຕໍ່ເຂົ້າສາຂາ ➔ ລະບົບຈະແຈ້ງ Push Alert *"📦 ມີບິນສົ່ງຕໍ່ເຂົ້າສາຂາ"*
2. ເປີດໜ້າ <span class="path">ຂົນສົ່ງ › ລໍຖ້າຈັດຖ້ຽວ</span>
3. ບິນຈະປາກົດໃນຄິວອັດຕະໂນມັດ ➔ ຈັດຄົນຂັບ local ຈັດສົ່ງຕໍ່ຫາລູກຄ້າ

---

## 🗂️ ໝວດ B: ຫົວໜ້າ / ຜູ້ຄຸມ (Supervisor)

### 📌 WI-B1: ອະນຸມັດ / ຕີກັບ ໃບງານ (Approve / Reject Job)
1. ເປີດເມນູ <span class="path">ອະນຸມັດ › ລໍອະນຸມັດ</span>
2. ກວດສອບ: ລົດ / ຄົນຂັບ / ນ້ຳໜັກ (kg) / ເສັ້ນທາງ (SLA < 2h)
3. **ຖ້າຖືກຕ້ອງ:** ກົດ **ອະນຸມັດ** ➔ ໃບງານໄປ *ລໍຖ້າຮັບຖ້ຽວ* (Push Alert ຫາຄົນຂັບ)
4. **ຖ້າບໍ່ຖືກ:** ກົດ **ຕີກັບ** ➔ ໃສ່ເຫດຜົນ ➔ ເດັ້ງກັບ Office ແກ້ໄຂ

---

### 📌 WI-B2: ຕິດຕາມ GPS Realtime (Live GPS Tracking)
1. ເປີດເມນູ <span class="path">ຕິດຕາມ › ແຜນທີ່ລົດ</span> ຫຼື <span class="path">ແຜນທີ່ມືຖື</span>
2. ເບິ່ງຕຳແໜ່ງລົດ, ສະຖານະແນວ, ຄວາມໄວ (km/h) Realtime
3. ກົດທີ່ລົດ ເພື່ອເບິ່ງລາຍລະອຽດໃບງານ ແລະ ເສັ້ນທາງແລ່ນ

---

## 🗂️ ໝວດ C: ຄົນຂັບລົດ (Driver App)

### 📌 WI-C1: ຮັບຖ້ຽວ & ເບີກເຄື່ອງ (Receive Job & Pickup)
1. Login ແອັບມືຖື ➔ ເປີດເມນູ **ໃບງານຂອງຂ້ອຍ**
2. ກົດ **ຮັບຖ້ຽວ (Receive Job)**
3. ໄປຮັບສິນຄ້າຢູ່ສາງ ➔ ກວດຈຳນວນ ➔ ກົດ **ເບີກເຄື່ອງສຳເລັດ**

---

### 📌 WI-C2: ເລີ່ມຈັດສົ່ງ (Start Delivery)
1. ກວດຄວາມຮຽບຮ້ອຍເທິງລົດ (ກວດ Battery, GPS ເປີດ)
2. ກົດ **ເລີ່ມຈັດສົ່ງ (Start Delivery)**
3. (ຖ່າຍຮູບເລີ່ມງານຖ້າລະບົບກຳນົດ) ➔ ລະບົບເລີ່ມສົ່ງ GPS Realtime

---

### 📌 WI-C3: ເຊັກອິນ & ສົ່ງບິນສຳເລັດ (Check-in & Deliver)
1. ຮອດຈຸດສົ່ງ ➔ ກົດ **ເຊັກອິນ (Check-in)**
2. ມອບສິນຄ້າໃຫ້ລູກຄ້າ ➔ ກົດ **ຖ່າຍຮູບຫຼັກຖານ** (ສິນຄ້າ + ລາຍເຊັນ)
3. **ຖ້າບິນມີປ້າຍ 💰 COD** ➔ ເກັບເງິນກ່ອນມອບສິນຄ້າ (ເບິ່ງ WI-C9)
4. ກົດ **ສົ່ງບິນສຳເລັດ** ➔ ບິນປ່ຽນສະຖານະເປັນ *ຈັດສົ່ງສຳເລັດ*

---

### 📌 WI-C9: ເກັບເງິນປາຍທາງ COD (Cash on Delivery)
**ບິນໃດແມ່ນ COD?** ERP ໝາຍໃຫ້ເອງ — ບິນທີ່ເລກຂຶ້ນຕົ້ນດ້ວຍ `COD…`
(CODPB ປະປາ · CODCE ໄຟຟ້າ · CODAC ແອ · CODSP ອາໄຫຼ່).
ໃນແອັບຈະຂຶ້ນ **ຕ້ອງເກັບ X ກີບ** ຢູ່ບິນນັ້ນ ແລະ ຢູ່ໜ້າຈໍ web ມີປ້າຍ 💰 COD.

1. ເກັບເງິນຈາກລູກຄ້າ **ກ່ອນ** ມອບສິນຄ້າ
2. ຕອນກົດ **ສົ່ງບິນສຳເລັດ** ໃຫ້ປ້ອນ:
   - **ຍອດທີ່ເກັບໄດ້** (ກີບ)
   - **ວິທີຊຳລະ**: ເງິນສົດ · ໂອນ · ສົດ+ໂອນ · ບໍ່ໄດ້ເກັບ
   - **ເລກສະລິບ** — ບັງຄັບ ຖ້າເລືອກ ໂອນ ຫຼື ສົດ+ໂອນ
   - **ເຫດຜົນ** — ບັງຄັບ ຖ້າເກັບບໍ່ຄົບ ຫຼື ເກີນ
3. ລະບົບຈະ **ບໍ່ຍອມໃຫ້ປິດບິນ** ຖ້າຂໍ້ມູນຂ້າງເທິງບໍ່ຄົບ
4. ຫ້ອງຈັດສົ່ງ + ການເງິນ ຈະໄດ້ຮັບແຈ້ງເຕືອນທັນທີ (ພ້ອມເຕືອນພິເສດ ຖ້າເກັບຂາດ)
5. ຈົບຖ້ຽວແລ້ວ ➔ **ມອບເງິນສົດໃຫ້ການເງິນ** (ເບິ່ງ WI-A8)

> ⚠️ ເງິນທີ່ລູກຄ້າ **ໂອນ** ເຂົ້າບັນຊີ ບໍ່ນັບເປັນເງິນທີ່ຄົນຂັບຕ້ອງມອບ —
> ມອບສະເພາະ **ເງິນສົດ**.

---

### 📌 WI-C4: ສົ່ງບໍ່ໄດ້ / ສົ່ງຄືນ / ທະຍອຍສົ່ງ (Partial & Return)
