# 📖 ຄູ່ມືການໃຊ້ງານ ODG TMS (User Manual)

ເອກະສານນີ້ອະທິບາຍ **ທຸກໜ້າ / ທຸກເມນູ / ທຸກຟັງຊັນ** ຂອງລະບົບ ODG TMS (Transport Management System) ຢ່າງລະອຽດ.

---

## 1. ການເຂົ້າສູ່ລະບົບ (Login & Access)

### 1.1 Web Dashboard (ຄອມພິວເຕີ)
1. ເປີດ Browser ໄປທີ່ URL ຂອງລະບົບ (ເຊັ່ນ `https://tms.odien.net`).
2. ປ້ອນ **ຊື່ຜູ້ໃຊ້ (Username)** ແລະ **ລະຫັດຜ່ານ (Password)** (ໃຊ້ບັນຊີ ERP ເດີມ).
3. ກົດ **ເຂົ້າສູ່ລະບົບ (Login)**.
4. ຖ້າປ້ອນບໍ່ຖືກ ລະບົບຈະແຈ້ງເຕືອນ *"ຊື່ຜູ້ໃຊ້ ຫຼື ລະຫັດຜ່ານບໍ່ຖືກຕ້ອງ"*.

> 🔒 **Security Note:** ລະບົບຈຳກັດການ Login ບໍ່ເກີນ **10 ຄັ້ງ/ນາທີ** ຕໍ່ 1 IP address. ຖ້າຖືກລັອກ ໃຫ້ລໍຖ້າ 1 ນາທີ ແລ້ວລອງໃໝ່.

### 1.2 ແອັບຄົນຂັບ (ມືຖື Handheld / Smartphone)
- ຄົນຂັບ Login ດ້ວຍ User/Pass ດຽວກັນ.
- Session ມີອາຍຸ **8 ຊົ່ວໂມງ** (ລະບົບຕໍ່ Refresh Token ອັດຕະໂນມັດ).
- **ຂໍ້ຕ້ອງເຮັດ:** ເມື່ອ Login ຄັ້ງທຳອິດ ຕ້ອງອະນຸຍາດສິດ **"Location Always" (ຕຳແໜ່ງຕະຫຼອດເວລາ)** ແລະ **"Notifications" (ການແຈ້ງເຕືອນ)** ໃຫ້ຄົບຖ້ວນ.

## 2. ໜ້າຫຼັກ (Dashboard Overview)

ຫຼັງຈາກ Login ເຂົ້າລະບົບ ຈະພົບກັບໜ້າ **Dashboard** ສະຫຼຸບພາບລວມ:
- **Status Summary Cards:** ຈຳນວນບິນໃນແຕ່ລະສະຖານະ (ລໍຖ້າຈັດຖ້ຽວ, ອະນຸມັດ, ກຳລັງສົ່ງ, ສຳເລັດ, ສົ່ງບໍ່ຄົບ).
- **Active Jobs Map:** ແຜນທີ່ລົດທີ່ກຳລັງແລ່ນຈັດສົ່ງ Realtime.
- **Alert & Inbox:** ກ່ອງຂໍ້ຄວາມ ແລະ ແຈ້ງເຕືອນວຽກດ່ວນ/ບິນຄ້າງ.

## 3. ໝວດ "ຂົນສົ່ງ" — ຫົວໃຈຂອງລະບົບ (Transport Module)

ໝວດນີ້ແມ່ນສາຍວຽກຫຼັກ. ແຕ່ລະເມນູຄື **1 ສະຖານະໃນ 11 ສະຖານະ** ຂອງວົງຈອນຊີວິດບິນ:

| ເມນູ | ສະຖານະບິນ | ໜ້າທີ່ & ຟັງຊັນການໃຊ້ງານ |
|------|-----------|---------------------------|
| **ລໍຖ້າຈັດຖ້ຽວ** | `pending` | ບິນຮັບເຂົ້າຈາກ ERP. ເລືອກບິນ ➔ ກຳນົດ ວັນສົ່ງ / ຮອບ / ເສັ້ນທາງ ➔ ຈັດເຂົ້າໃບງານ (ຫຼື ແຍກບິນຕາມສາຂາ) |
| **ບິນລໍຕາມເສັ້ນທາງ** | `route_planned` | ບິນທີ່ຈັດເສັ້ນທາງແລ້ວ. ຈັດກຸ່ມບິນ ➔ ເລືອກ ລົດ + ຄົນຂັບ ➔ ສ້າງໃບງານ |
| **ໃບງານ / ລໍຖ້າອະນຸມັດ** | `job_created` | ໃບງານທີ່ສ້າງແລ້ວ. ກວດຄວາມຖືກຕ້ອງ ແລະ ນ້ຳໜັກບັນຈຸ ➔ ກົດ **ສົ່ງອະນຸມັດ** |
| **ລໍຖ້າຮັບຖ້ຽວ** | `approved` | ໃບງານທີ່ອະນຸມັດແລ້ວ. ຕິດຕາມວ່າຄົນຂັບກົດ **ຮັບຖ້ຽວ** ໃນແອັບມືຖືແລ້ວຫຼືຍັງ |
| **ລໍຖ້າເບີກເຄື່ອງ** | `job_received` | ຄົນຂັບຮັບຖ້ຽວແລ້ວ. ປະສານສາງ ➔ ເບີກສິນຄ້າ ➔ ກວດຈຳນວນ |
| **ລໍຖ້າຈັດສົ່ງ** | `picked_up` | ເບີກເຄື່ອງແລ້ວ. ກວດຄວາມຮຽບຮ້ອຍເທິງລົດ ➔ ຄົນຂັບກົດ **ເລີ່ມຈັດສົ່ງ** |
| **ກຳລັງຈັດສົ່ງ** | `in_transit` | ລົດອອກແລ່ນ. ຕິດຕາມຕຳແໜ່ງ Realtime ຜ່ານ GPS Hardware / ມືຖື |
| **ຈັດສົ່ງສຳເລັດ** | `delivered` | ບິນສົ່ງຮອດລູກຄ້າຄົບ 100%. ກວດຮູບຫຼັກຖານການສົ່ງ ແລະ ລາຍເຊັນລູກຄ້າ |
| **ບິນສົ່ງບໍ່ຄົບ** | `partially_delivered` / `returned` | ສົ່ງໄດ້ບາງສ່ວນ / ສົ່ງຄືນ / ຍົກເລີກ. ຕິດຕາມສາເຫດ ➔ ຈັດຮອບຈັດສົ່ງຕໍ່ໄປ |
| **ຄົນຂັບປິດງານ** | `job_completed` | ຄົນຂັບກົດປິດໃບງານຈາກແອັບ. Office ກວດຮັບ ➔ ກົດ **ປິດສຳເລັດ** (ຫຼື ຕີກັບ/Revert) |
| **ປິດສຳເລັດແລ້ວ** | `closed` | ຈົບຂະບວນການ 100%. ຂໍ້ມູນບັນທຶກເຂົ້າປະຫວັດ, ລາຍງານ KPI ແລະ Leaderboard |

## 4. ໝວດ "ອະນຸມັດ" (Approval Module)

- **ລໍອະນຸມັດ (`/approvals/pending`)**: ລາຍການໃບງານທີ່ລໍການອະນຸມັດຈາກຫົວໜ້າ.
  - ຫົວໜ້າກວດສອບ: ຄວາມເໝາະສົມຂອງລົດ/ຄົນຂັບ, ນ້ຳໜັກບັນຈຸ (kg), ເສັ້ນທາງ.
  - ກົດ **ອະນຸມັດ (Approve)** ➔ ໃບງານໄປສະຖານະ *ລໍຖ້າຮັບຖ້ຽວ*.
  - ກົດ **ຕີກັບ (Reject)** ➔ ໃສ່ເຫດຜົນ ➔ ໃບງານຍ້ອນກັບໄປ Office ແກ້ໄຂ.
- **ອະນຸມັດແລ້ວ (`/approvals/history`)**: ປະຫວັດການອະນຸມັດ ແລະ ລາຍງານສະຫຼຸບ.

## 5. ໝວດ "ຕິດຕາມ" (Tracking Module)

| ເມນູ | ການນຳໃຊ້ & ຟັງຊັນ |
|------|-------------------|
| **ຕິດຕາມສິນຄ້າ** | ຄົ້ນຫາເລກບິນ, ເບິ່ງປະຫວັດການແນວນຳ ແລະ ສະຖານະບິນ |
| **ບິນສົ່ງບໍ່ສຳເລັດ** | ລວມບິນທີ່ຍັງສົ່ງບໍ່ໄດ້ (ຝ່າຍຂາຍໃຊ້ຕິດຕາມ ແລະ ຍ້າຍວັນຈັດສົ່ງ) |
| **ແຜນທີ່ລົດ** | ແຜນທີ່ຕຳແໜ່ງລົດ Realtime ຈາກ GPS Hardware |
| **ແຜນທີ່ມືຖື** | ແຜນທີ່ຕຳແໜ່ງ Realtime ຈາກ GPS ແອັບມືຖືຄົນຂັບ |
| **ເສັ້ນທາງມືຖືຄົນຂັບ** | ເບິ່ງເສັ້ນທາງທີ່ຄົນຂັບແລ່ນຜ່ານຍ້ອນຫຼັງ (Playback Route) |
| **ສະຫຼຸບ GPS ປະຈຳວັນ** | ສະຖິຕິການໃຊ້ GPS, ກິໂລແມັດ ແລະ ໄລຍະເວລາແລ່ນລົດ |

## 6. ໝວດ "ລາຍງານ" (Reports Module)

ສາມາດເລືອກຊ່ວງວັນທີ, ສາຂາ, ເສັ້ນທາງ ແລ້ວກົດ **ສ້າງລາຍງານ / Export Excel**:
- **ລາຍງານປະຈຳວັນ / ເຄື່ອນໄຫວບິນ / ເຄື່ອນໄຫວສິນຄ້າ:** ສະຫຼຸບກິດຈະກຳການຈັດສົ່ງປະຈຳວັນ.
- **ລາຍງານບິນຄ້າງສົ່ງ / ສົ່ງສຳເລັດ / ຍົກເລີກ:** ສະຖິຕິບິນແຍກຕາມສະຖານະ.
- **ລາຍງານຕາມຄົນຂັບ / ຕາມລົດ / ຕາມບິນ:** ວິເຄາະລົງລາຍລະອຽດແຕ່ລະຄົນ/ຄັນ.
- **ລາຍງານນຳໃຊ້ລົດປະຈຳເດືອນ:** ສະຫຼຸບປະສິດທິພາບການໃຊ້ລົດ.
- **Leaderboard ຄົນຂັບ:** ຈັດອັນດັບຜົນງານຄົນຂັບ (ຈຳນວນບິນສົ່ງສຳເລັດ, ຄະແນນດາວ, ເວລາ).

## 7. ໝວດ "ນ້ຳມັນ" (Fuel Management Module)

- **ບັນທຶກເຕີມນ້ຳມັນ (`/fuel`)**:
  - ຄົນຂັບບັນທຶກຈາກແອັບມືຖື: ຈຳນວນເງິນ (ກີບ), ຈຳນວນລິດ, ເລກກິໂລແມັດ (Odometer) + ຖ່າຍຮູບໃບບິນ.
  - Office ກວດສອບຄວາມຖືກຕ້ອງ ແລະ ອະນຸມັດຍອດນ້ຳມັນ.

## 8. ໝວດ "ທັນໃຈ Express" (ThunJai Express)

ບໍລິການຂົນສົ່ງດ່ວນ ThunJai:
- **ຈັດການ ThunJai:** ຈັດການໃບຂົນສົ່ງດ່ວນ ແລະ ຕິດຕາມສະຖານະ.
- **ສ້າງ Order ThunJai:** ສ້າງ Order ຂົນສົ່ງດ່ວນໃໝ່.
- **ພາບລວມ ThunJai:** ສະຫຼຸບຍອດ Order ແລະ ປະສິດທິພາບ.

## 9. ໝວດ "ການຈັດການ" (Master Data & Admin)

- **ຂໍ້ມູນລົດ & ປະເພດລົດ:** ຈັດການທະບຽນລົດ, ນ້ຳໜັກບັນຈຸສູງສຸດ, ປະເພດລົດ.
- **ຂໍ້ມູນພະນັກງານ:** ຈັດການຂໍ້ມູນຄົນຂັບ, ພະນັກງານ Office, ຫົວໜ້າ.
- **ເສັ້ນທາງ & ຮອບຈັດສົ່ງ:** ກຳນົດ Master ເສັ້ນທາງຂົນສົ່ງ ແລະ ຮອບເວລາ.
- **Audit Log:** ກວດສອບປະຫວັດການ Login, ການແກ້ໄຂຂໍ້ມູນ ແລະ ການເຮັດວຽກຂອງຜູ້ໃຊ້.

## 10. ຕິດຕາມສາທາລະນະ & ປະເມີນຄະແນນ (Public Portal)

- **`https://tms.odien.net/track`**: ລູກຄ້າເປີດ ໃສ່ເລກບິນ ➔ ເບິ່ງສະຖານະບິນ ແລະ ຕຳແໜ່ງລົດ Realtime ໂດຍບໍ່ຕ້ອງ Login.
- **`https://tms.odien.net/rate`**: ລູກຄ້າໃຫ້ຄະແນນຄວາມພຶງພໍໃຈ 1-5 ດາວ + ຄຳຕິຊົມ.
