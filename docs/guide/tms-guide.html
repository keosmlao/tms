02

Workflow — ຂັ້ນຕອນການເຮັດວຽກ

ໃຜຮັບຊ່ວງໃສ ແລະ ເຮັດຢູ່ບ່ອນໃດ ໃນແຕ່ລະຂັ້ນ (swimlane).

ຂັ້ນສະຖານະຜູ້ຮັບຜິດຊອບເຄື່ອງມືຜົນທີ່ໄດ້
1–3ຈັດຖ້ຽວ → ເສັ້ນທາງ → ໃບງານoffice / dispatchWebໃບງານພ້ອມສົ່ງອະນຸມັດ
4ອະນຸມັດຫົວໜ້າ / ຜູ້ຄຸມWebໃບງານຖືກອະນຸມັດ
5–7ຮັບຖ້ຽວ → ເບີກເຄື່ອງ → ພ້ອມສົ່ງຄົນຂັບ + ສາງແອັບເບີກສິນຄ້າຄົບ
8ກຳລັງຈັດສົ່ງຄົນຂັບແອັບ + GPSຕິດຕາມ realtime
9ສຳເລັດ / ບໍ່ຄົບຄົນຂັບແອັບຮູບຫຼັກຖານການສົ່ງ
10–11ປິດງານ → ປິດສຳເລັດຄົນຂັບ → officeແອັບ → Webເຂົ້າລາຍງານ
ຈຸດຕັດສິນ · ອະນຸມັດ (ຂັ້ນ 4)

ກວດ ລົດ/ຄົນຂັບ/ນ້ຳໜັກ/ເສັ້ນທາງ. ຜ່ານ → ລໍຮັບຖ້ຽວ · ບໍ່ຜ່ານ → ຕີກັບພ້ອມເຫດຜົນ.

ຈຸດຕັດສິນ · ສົ່ງ (ຂັ້ນ 9)

ຄົບ → complete + ຮູບ · ບໍ່ຄົບ → return + ເຫດຜົນ → ຈັດຮອບຕໍ່ໄປ · ຍົກເລີກ → ຕ້ອງໄດ້ອະນຸຍາດ.

ຈຸດຕັດສິນ · ກວດຮັບ (ຂັ້ນ 11)

office ກວດຮູບ + ຈຳນວນ. ຂາດ/ຜິດ → ຕີກັບໃຫ້ຄົນຂັບ (revert/edit) ກ່ອນປິດ.

ຂະບວນການເສີມ · GPS

ຂະນະສົ່ງ ແອັບສົ່ງພິກັດອັດຕະໂນມັດ. ສົ່ງບໍ່ໄດ້ → ລາຍງານເຫດຜົນ (GPS ປິດ / ບໍ່ອະນຸຍາດ / token ໝົດ).

ຂະບວນການເສີມ · ແຈ້ງເຕືອນ

Push ຫາຄົນຂັບເມື່ອມີໃບງານໃໝ່/ອະນຸມັດ; cron ເຕືອນ dispatch/KPI; ຝ່າຍຂາຍໄດ້ຮັບເມື່ອບິນປ່ຽນສະຖານະ.

03

SOP — ລະບຽບການປະຕິບັດງານ

ມາດຕະຖານ ໃຜຕ້ອງເຮັດຫຍັງ ເມື່ອໃດ ໃຫ້ສະໝ່ຳສະເໝີ ແລະ ກວດສອບໄດ້.

Office / Dispatch

SOP-1 · ຈັດຖ້ຽວ & ໃບງານ
  1. ຕົ້ນວັນ: ກວດ ລໍຖ້າຈັດຖ້ຽວ ທັງໝົດ
  2. ຈັດ ວັນ/ຮອບ/ເສັ້ນທາງ, ຈັດບິນທາງດຽວກັນເຂົ້າໃບງານດຽວ
  3. ຈັບຄູ່ ລົດ + ຄົນຂັບ ໃຫ້ພໍກັບນ້ຳໜັກ
  4. ກວດ → ສົ່ງອະນຸມັດ
  5. ຕິດຕາມບິນຄ້າງ + GPS ຕະຫຼອດວັນ
  6. ກວດຮັບ → ປິດງານ; ທ້າຍວັນອອກລາຍງານ

ຕ້ອງ: ບໍ່ເກີນຄວາມສາມາດລົດ · ຍົກເລີກຕ້ອງມີເຫດຜົນ+ອະນຸຍາດ

ຫົວໜ້າ / ຜູ້ຄຸມ

SOP-2 · ອະນຸມັດ & KPI
  1. ອະນຸມັດໃບງານພາຍໃນ SLA
  2. ຕິດຕາມ realtime ຜ່ານແຜນທີ່
  3. ຕິດຕາມ KPI ຈາກລາຍງານ
  4. ຈັດການເຫດ: ຄ້າງນານ / ບໍ່ຄົບ / ຫຼຸດເສັ້ນທາງ
  5. ພິຈາລະນາຄຳຂໍ ຍົກເລີກ/ແກ້ໄຂ

ຕ້ອງ: ບໍ່ອະນຸມັດຂໍ້ມູນບໍ່ຄົບ · ຕີກັບຕ້ອງມີເຫດຜົນ

ຄົນຂັບລົດ

SOP-3 · ຮັບ–ສົ່ງ ຕໍ່ຖ້ຽວ
  1. ກ່ອນອອກ: login, ເປີດ GPS+Notification, ກວດ battery
  2. ຮັບຖ້ຽວ → ເບີກເຄື່ອງ (ກວດຈຳນວນ)
  3. ເລີ່ມສົ່ງ → ເຊັກອິນ → ຖ່າຍຮູບ → ສົ່ງສຳເລັດ
  4. ບໍ່ຄົບ → ສົ່ງຄືນ+ເຫດຜົນ
  5. ບັນທຶກນ້ຳມັນ → ປິດງານ

ຕ້ອງ: ບໍ່ສົ່ງສຳເລັດໂດຍບໍ່ມີຮູບ · ຫ້າມປິດ GPS · ຮູບ < 8MB

ຝ່າຍຂາຍ

SOP-4 · ຕິດຕາມລູກຄ້າ
  1. ຕິດຕາມ ບິນສົ່ງບໍ່ສຳເລັດ ຂອງລູກຄ້າຕົນ
  2. ກຳນົດວັນຈັດສົ່ງຮ່ວມ office
  3. ຢືນຢັນ ບິນສົ່ງສຳເລັດ + ຕິດຕາມຄຳຕິຊົມ

ໝາຍເຫດ: ບັນຊີຝ່າຍຂາຍຖືກຈຳກັດຂອບເຂດການເຫັນຂໍ້ມູນ

04

WI — ຄຳແນະນຳການເຮັດວຽກ

ບັດຂັ້ນຕອນ ເຮັດຕາມໄດ້ທັນທີ 1-2-3. ແຕ່ລະບັດ = 1 ວຽກ.

WI-A1

ຈັດຖ້ຽວບິນ

  1. ເມນູ ຂົນສົ່ງ › ລໍຖ້າຈັດຖ້ຽວ
  2. ໝາຍເລືອກບິນ (ໄດ້ຫຼາຍໃບ)
  3. ກຳນົດ ວັນ · ຮອບ · ເສັ້ນທາງ
  4. ບັນທຶກ → ໄປ ບິນລໍຕາມເສັ້ນທາງ
WI-A2

ສ້າງໃບງານ

  1. ເມນູ ບິນລໍຕາມເສັ້ນທາງ
  2. ເລືອກກຸ່ມ → ສ້າງໃບງານ
  3. ເລືອກ ລົດ + ຄົນຂັບ (ກວດນ້ຳໜັກ)
  4. ສົ່ງອະນຸມັດ
WI-A3

ກວດຮັບ & ປິດງານ

  1. ເມນູ ຄົນຂັບປິດງານ
  2. ກວດຮູບ + ຈຳນວນ ຕໍ່ບິນ
  3. ຄົບ → ປິດສຳເລັດ
  4. ຂາດ → ຕີກັບພ້ອມໝາຍເຫດ
WI-B1

ອະນຸມັດ / ຕີກັບ

  1. ເມນູ ອະນຸມັດ › ລໍອະນຸມັດ
  2. ກວດ ລົດ/ຄົນຂັບ/ນ້ຳໜັກ/ເສັ້ນທາງ
  3. ຖືກ → ອະນຸມັດ · ບໍ່ຖືກ → ຕີກັບ+ເຫດຜົນ
WI-C1–3

ຄົນຂັບ: ຮັບ → ສົ່ງ

  1. ຮັບຖ້ຽວ → ເບີກເຄື່ອງ (ກວດຈຳນວນ)
  2. ເລີ່ມຈັດສົ່ງ (GPS ຫ້າມປິດ)
  3. ຮອດຈຸດ → ເຊັກອິນ
  4. ມອບ → ຖ່າຍຮູບ → ສົ່ງບິນສຳເລັດ
WI-C4–6

ຄົນຂັບ: ບໍ່ຄົບ & ນ້ຳມັນ

  1. ບໍ່ຄົບ → ສົ່ງຄືນ + ເຫດຜົນ (+ຮູບ)
  2. ຍົກເລີກ → ເຫດຜົນ (ຕ້ອງອະນຸຍາດ)
  3. ນ້ຳມັນ → ໃສ່ຈຳນວນ + ຮູບໃບບິນ
  4. ຈົບ → ປິດງານ
WI-D1

ຝ່າຍຂາຍ: ຕິດຕາມບິນ
