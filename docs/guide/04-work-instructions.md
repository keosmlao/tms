# WI — ຄຳແນະນຳການເຮັດວຽກ (Work Instructions)

**ບັດຂັ້ນຕອນ** ແບບເຮັດຕາມໄດ້ທັນທີ ເທື່ອລະ 1-2-3. ແຕ່ລະ WI = 1 ວຽກ.

---

## WI-A · ພະນັກງານ Office / Dispatch

### WI-A1 — ຈັດຖ້ຽວບິນ
1. ເມນູ **ຂົນສົ່ງ › ລໍຖ້າຈັດຖ້ຽວ**.
2. ໝາຍເລືອກບິນທີ່ຈະຈັດ (ໝາຍໄດ້ຫຼາຍໃບພ້ອມກັນ).
3. ກຳນົດ **ວັນຈັດສົ່ງ**, **ຮອບການຈັດສົ່ງ**, **ເສັ້ນທາງ**.
4. ກົດ **ບັນທຶກ** → ບິນຍ້າຍໄປ *ບິນລໍຕາມເສັ້ນທາງ*.
5. ✅ ກວດ: ບິນຫາຍຈາກ *ລໍຖ້າຈັດຖ້ຽວ* ແລ້ວ.

### WI-A2 — ສ້າງໃບງານ (ຈັບຄູ່ລົດ + ຄົນຂັບ)
1. ເມນູ **ຂົນສົ່ງ › ບິນລໍຕາມເສັ້ນທາງ**.
2. ເລືອກກຸ່ມບິນຕາມເສັ້ນທາງ → ກົດ **ສ້າງໃບງານ**.
3. ເລືອກ **ລົດ** ແລະ **ຄົນຂັບ** (ກວດນ້ຳໜັກ/ປະລິມານບໍ່ໃຫ້ເກີນ).
4. ກົດ **ບັນທຶກ/ສົ່ງອະນຸມັດ** → ໃບງານໄປ *ໃບງານ/ລໍຖ້າອະນຸມັດ*.

### WI-A3 — ກວດຮັບ ແລະ ປິດງານ
1. ເມນູ **ຂົນສົ່ງ › ຄົນຂັບປິດງານ**.
2. ເປີດໃບງານ → ກວດ **ຮູບຫຼັກຖານ** ແລະ **ຈຳນວນສົ່ງ** ຕໍ່ບິນ.
3. ຄົບ/ຖືກ → ກົດ **ປິດສຳເລັດ** → ໄປ *ປິດສຳເລັດແລ້ວ*.
4. ຂາດ/ຜິດ → **ຕີກັບ** ໃຫ້ຄົນຂັບແກ້ໄຂ ພ້ອມໝາຍເຫດ.

### WI-A4 — ອອກລາຍງານ + Export Excel
1. ເມນູ **ລາຍງານ › (ເລືອກຊະນິດ)**.
2. ເລືອກ **ຊ່ວງວັນທີ** → ກົດ **ຄົ້ນຫາ**.
3. ກົດ **Export / Excel** ເພື່ອດາວໂຫຼດ.

### WI-A5 — ພິມ QR ຕຳແໜ່ງສົ່ງຂອງບິນ
1. ໜ້າ *ລໍຖ້າຈັດຖ້ຽວ* → ເລືອກບິນ → ກົດ **ພິມ QR ຕຳແໜ່ງ**.
2. ໜ້າໃໝ່ຈະເປີດ → ກົດ **Print**.

## WI-B · ຫົວໜ້າ / ຜູ້ຄຸມ

### WI-B1 — ອະນຸມັດ / ຕີກັບໃບງານ
1. ເມນູ **ອະນຸມັດ › ລໍອະນຸມັດ**.
2. ເປີດໃບງານ → ກວດ ລົດ/ຄົນຂັບ/ນ້ຳໜັກ/ເສັ້ນທາງ.
3. ຖືກຕ້ອງ → ກົດ **ອະນຸມັດ** (ໃບງານໄປ *ລໍຖ້າຮັບຖ້ຽວ*).
4. ບໍ່ຖືກ → ກົດ **ຕີກັບ** + ພິມເຫດຜົນ.

### WI-B2 — ຕິດຕາມລົດ realtime
1. ເມນູ **ຕິດຕາມ › ແຜນທີ່ລົດ** (GPS ຮາດແວ) ຫຼື **ແຜນທີ່ມືຖື** (GPS ຄົນຂັບ).
2. ຄລິກໝຸດລົດ → ເບິ່ງລາຍລະອຽດ/ຄວາມໄວ/ເວລາ.
3. ບໍ່ເຫັນລົດ → ໄປ **ຕິດຕາມ › ສະຫຼຸບ GPS ປະຈຳວັນ** ກວດສະຖານະ GPS.

### WI-B3 — ເບິ່ງ KPI ຄົນຂັບ
1. ເມນູ **ລາຍງານ › Leaderboard ຄົນຂັບ** ຫຼື **ຄົນຂັບ/ເດືອນ**.
2. ຮຽງຕາມ ຈຳນວນສົ່ງສຳເລັດ / ຄ້າງ.

---

## WI-C · ຄົນຂັບລົດ (ແອັບມືຖື) {#wi-c-ຄົນຂັບລົດ}

### WI-C0 — ກຽມກ່ອນອອກງານ
1. ເປີດແອັບ → **login**.
2. ອະນຸຍາດ **Location (ຕະຫຼອດເວລາ)** ແລະ **Notification**.
3. ກວດ battery ແລະ ສັນຍານເນັດ.

### WI-C1 — ຮັບຖ້ຽວ → ເບີກເຄື່ອງ
1. ເປີດ **ໃບງານ** ທີ່ໄດ້ຮັບມອບ → ກົດ **ຮັບຖ້ຽວ (receive)**.
2. ໄປສາງ → ກົດ **ເບີກເຄື່ອງ (pickup)** ຕໍ່ບິນ, ກວດຈຳນວນໃຫ້ຄົບ.

### WI-C2 — ເລີ່ມ ແລະ ຈັດສົ່ງ
1. ພ້ອມແລ້ວ → ກົດ **ເລີ່ມຈັດສົ່ງ (start)** (ຖ່າຍ *ຮູບເລີ່ມງານ* ຖ້າກຳນົດ).
2. GPS ຈະສົ່ງຕຳແໜ່ງອັດຕະໂນມັດ — **ຫ້າມປິດ**.
3. ຮອດຈຸດ → ກົດ **ເຊັກອິນ (checkin)** ຕໍ່ບິນ.

### WI-C3 — ສົ່ງບິນສຳເລັດ (ຄົບ)
1. ມອບສິນຄ້າ → ກົດ **ສົ່ງບິນສຳເລັດ (complete)**.
2. **ຖ່າຍຮູບຫຼັກຖານ** (ສິນຄ້າ/ຜູ້ຮັບ/ລາຍເຊັນ) — ບັງຄັບ.
3. ຢືນຢັນ → ບິນເປັນ *ຈັດສົ່ງສຳເລັດ*.

### WI-C4 — ສົ່ງບໍ່ຄົບ / ສົ່ງຄືນ
1. ກົດ **ສົ່ງຄືນ (return)** → ເລືອກ/ພິມ **ເຫດຜົນ**.
2. ຖ່າຍຮູບ (ຖ້າມີ) → ຢືນຢັນ → ບິນເປັນ *ບິນສົ່ງບໍ່ຄົບ*.

### WI-C5 — ຍົກເລີກບິນ
1. ກົດ **ຍົກເລີກ (cancel)** → ພິມເຫດຜົນ (ຕ້ອງໄດ້ຮັບອະນຸຍາດ).

### WI-C6 — ບັນທຶກເຕີມນ້ຳມັນ
1. ເມນູ **ນ້ຳມັນ** ໃນແອັບ → **ເພີ່ມ**.
2. ໃສ່ **ຈຳນວນເງິນ/ລິດ** + **ຖ່າຍຮູບໃບບິນ** → ບັນທຶກ.

### WI-C7 — ແກ້ໄຂການສົ່ງທີ່ຜິດ
1. ເປີດບິນທີ່ *ສົ່ງສຳເລັດ* → ກົດ **ແກ້ໄຂ (edit)** ຫຼື **ຍ້ອນກັບ (revert)**.
2. ແກ້ຮູບ/ຈຳນວນ → ບັນທຶກ.

### WI-C8 — ປິດໃບງານ
1. ຈົບທຸກບິນ → ຖ່າຍ *ຮູບຈົບງານ* (ຖ້າກຳນົດ) → ກົດ **ປິດງານ (complete job)**.

> ⚠️ ຖ້າ **ກົດສົ່ງບໍ່ໄດ້**: ກວດເນັດ; ຖ້າ token ໝົດອາຍຸ (ຫຼຸດ 8 ຊມ) ໃຫ້ **login ໃໝ່**; ຫຼຸດຂະໜາດຮູບໃຫ້ < 8MB.

## WI-D · ຝ່າຍຂາຍ

### WI-D1 — ຕິດຕາມບິນລູກຄ້າ
1. ເມນູ **ຝ່າຍຂາຍ › ບິນສົ່ງບໍ່ສຳເລັດ**.
2. ຄົ້ນຫາຕາມລູກຄ້າ/ເລກບິນ → ເບິ່ງສະຖານະ.

### WI-D2 — ກຳນົດວັນຈັດສົ່ງ
1. ເມນູ **ຝ່າຍຂາຍ › ກຳນົດວັນຈັດສົ່ງ** → ເລືອກບິນ → ໃສ່ວັນ → ບັນທຶກ (ປະສານ office).

---

## WI-E · ລູກຄ້າ (ສາທາລະນະ)

### WI-E1 — ຕິດຕາມສະຖານະບິນ
1. ເປີດ `/track` → ໃສ່ **ເລກບິນ** → ເບິ່ງສະຖານະ.

### WI-E2 — ໃຫ້ຄະແນນການບໍລິການ
1. ເປີດ `/rate` (ຫຼື ລິ້ງທີ່ໄດ້ຮັບ) → ເລືອກຄະແນນ + ຄຳຕິຊົມ → ສົ່ງ.
