## 🎯 ຄວາມແຕກຕ່າງຂອງເອກະສານ 4 ຊະນິດ

- **ຄູ່ມືການໃຊ້ງານ (User Manual)** = *“ປຸ່ມນີ້/ເມນູນີ້ຄືຫຍັງ?”* — ອະທິບາຍໜ້າຈໍ, ເມນູ, ແລະ ຟັງຊັນການໃຊ້ງານ.
- **Workflow** = *“ວຽກໄຫຼແນວໃດ?”* — ພາບລວມຂະບວນການ 11 ສະຖານະ, Swimlane, ແລະ ຈຸດຕັດສິນໃຈ.
- **SOP (Standard Operating Procedure)** = *“ໃຜຕ້ອງເຮັດຫຍັງ ເມື່ອໃດ ໃຫ້ໄດ້ມາດຕະຖານ?”* — ກົດລະບຽບ, ຄວາມຮັບຜິດຊອບ, ແລະ SLA.
- **WI (Work Instruction)** = *“ເຮັດວຽກນີ້ ກົດຫຍັງກ່ອນຫຼັງ?”* — ບັດຂັ້ນຕອນ 1-2-3 ທີ່ປະຕິບັດຕາມໄດ້ທັນທີ.

## 👥 Role Access Matrix (ຕາຕະລາງສິດການເຂົ້າເຖິງ)

| ບົດບາດ (Role) | Web Dashboard | ແອັບມືຖື | ຂອບເຂດຂໍ້ມູນ | ວຽກຫຼັກ |

| **office / dispatch** | ✅ | ❌ | ທັງໝົດ | ຈັດຖ້ຽວ, ສ້າງໃບງານ, ຕິດຕາມ GPS, ປິດງານ, ລາຍງານ |
| **ຫົວໜ້າ / ຜູ້ຄຸມ (supervisor)** | ✅ | ❌ | ທັງໝົດ | ອະນຸມັດໃບງານ (SLA < 2h), ຕິດຕາມ KPI, ຈັດການເຫດ |
| **ຄົນຂັບລົດ (driver)** | ❌ | ✅ | ສະເພາະໃບງານຕົນ | ຮັບຖ້ຽວ, ເບີກເຄື່ອງ, ຈັດສົ່ງ, ຖ່າຍຮູບ, ເຕີມນ້ຳມັນ |
| **ຝ່າຍຂາຍ (sales)** | ✅ | ❌ | ສະເພາະສາຍຂາຍຕົນ | ຕິດຕາມບິນບໍ່ສຳເລັດ, ຍ້າຍວັນຈັດສົ່ງ, ເບິ່ງຄະແນນ |
| **ຜູ້ດູແລລະບົບ (admin)** | ✅ | ❌ | ທັງໝົດ + Admin | Master Data, ສິດຜູ້ໃຊ້, Audit Log, System Security |

## 📖 ຄຳສັບຫຍໍ້ ແລະ ຄວາມໝາຍ (Glossary)

| ຄຳສັບ | ຄວາມໝາຍ |
|-------|---------|
| **ບິນ (Bill)** | ໃບບິນ / ໃບສັ່ງສິນຄ້າ / ໃບຂົນສົ່ງ ທີ່ຕ້ອງຈັດສົ່ງໃຫ້ລູກຄ້າ |
| **ໃບງານ (Job)** | ຊຸດການຈັດສົ່ງ 1 ຖ້ຽວ ທີ່ມອບໃຫ້ຄົນຂັບ 1 ຄົນ ແລະ ລົດ 1 ຄັນ (ປະກອບດ້ວຍຫຼາຍບິນ) |
| **ຖ້ຽວ (Trip)** | ຮອບການແລ່ນລົດຈັດສົ່ງ 1 ຮອບ |
| **ຈັດຖ້ຽວ** | ການເອົາບິນຫຼາຍໆບິນມາຈັດເຂົ້າໃບງານ/ລົດ/ຄົນຂັບ ແລະ ກຳນົດເສັ້ນທາງ |
| **ເສັ້ນທາງ (Route)** | ເສັ້ນທາງຈັດສົ່ງສິນຄ້າທີ່ກຳນົດໄວ້ລ່ວງໜ້າ |
| **ຮອບການຈັດສົ່ງ (Round)** | ຮອບເວລາຈັດສົ່ງ (ເຊັ່ນ ຮອບເຊົ້າ / ຮອບບ່າຍ) |
| **ທັນໃຈ Express** | ບໍລິການຂົນສົ່ງດ່ວນ ThunJai Express |
| **GPS Tracking** | ການຕິດຕາມຕຳແໜ່ງລົດ ແລະ ມືຖືຄົນຂັບແບບ Realtime |
| **ທະຍອຍສົ່ງ (Partial)** | ການຈັດສົ່ງໄດ້ບາງສ່ວນ ໂດຍມີຍອດເຫຼືອສິນຄ້າກັບເຂົ້າຄິວຈັດຖ້ຽວ |
| **ສົ່ງຕໍ່ສາຂາ (Forwarding)** | ການຂົນສົ່ງສິນຄ້າໄປມອບໃຫ້ສາຂາປາຍທາງ ເພື່ອຈັດສົ່ງຕໍ່ຫາລູກຄ້າ |
