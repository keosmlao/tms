# ຄູ່ມືລະບົບ ODG TMS — ສາລະບານ

ເອກະສານຊຸດນີ້ແມ່ນຄູ່ມືການໃຊ້ງານລະບົບບໍລິຫານການຂົນສົ່ງ **ODG TMS** (Transport Management System) ຄົບທັງລະບົບ — ສຳລັບ ພະນັກງານ office/dispatch, ຄົນຂັບລົດ, ຫົວໜ້າ/ຜູ້ຄຸມ ແລະ ຝ່າຍຂາຍ.

> **ຂອບເຂດ:** Web Dashboard (ຄອມພິວເຕີ/browser), ແອັບຄົນຂັບ (ມືຖື), ໜ້າຕິດຕາມສາທາລະນະ, GPS tracking, ລາຍງານ ແລະ ນ້ຳມັນ.

## ຄວາມແຕກຕ່າງຂອງເອກະສານ 4 ຊະນິດ

- **ຄູ່ມືການໃຊ້ງານ** = *ປຸ່ມນີ້ຄືຫຍັງ?* ອະທິບາຍໜ້າຈໍ ແລະ ໜ້າທີ່ຂອງແຕ່ລະເມນູ.
- **Workflow** = *ວຽກໄຫຼແນວໃດ?* ພາບໃຫຍ່ຂອງຂະບວນການ ແລະ ໃຜຮັບຊ່ວງໃສ.
- **SOP** = *ໃຜຕ້ອງເຮັດຫຍັງ ເມື່ອໃດ ໃຫ້ໄດ້ມາດຕະຖານ?* ກົດລະບຽບ ແລະ ຄວາມຮັບຜິດຊອບ.
- **WI** = *ເຮັດວຽກນີ້ ກົດຫຍັງກ່ອນຫຼັງ?* ຂັ້ນຕອນ 1-2-3 ແບບເຮັດຕາມໄດ້ທັນທີ.
