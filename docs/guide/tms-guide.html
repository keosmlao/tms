ຄູ່ມືການໃຊ້ງານ (User Manual)

ອະທິບາຍທຸກໜ້າ ແລະ ທຸກເມນູໃນລະບົບ ODG TMS ແຍກຕາມໝວດການໃຊ້ງານ.

💻 1.1 Web Dashboard (ຄອມພິວເຕີ)

ເປີດ Browser ໄປທີ່ URL ລະບົບ (ເຊັ່ນ tms.odien.net) ➔ Login ດ້ວຍບັນຊີ ERP ➔ ຖ້າປ້ອນຜິດເກີນ 10 ຄັ້ງ/ນາທີ ລະບົບຈະລັອກ IP 1 ນາທີ.

📱 1.2 ແອັບຄົນຂັບ (ມືຖື)

Login ດ້ວຍ User/Pass ດຽວກັນ, Session ໃຊ້ໄດ້ 8 ຊົ່ວໂມງ ➔ ຕ້ອງອະນຸຍາດ Location Always ແລະ Notification ໃຫ້ຄົບ ເພື່ອໃຫ້ GPS ແລະ ແຈ້ງເຕືອນເຮັດວຽກ.

02

Workflow — ຂັ້ນຕອນການເຮັດວຽກ & 10 ກໍລະນີພິເສດ

ວົງຈອນການເຮັດວຽກ 11 ຂັ້ນຕອນ ແລະ ວິທີຮັບມືກັບ 10 ກໍລະນີພິເສດໃນການຈັດສົ່ງ.

⚖️ ຈຸດຕັດສິນ 1: ການອະນຸມັດໃບງານ (ຂັ້ນ 4)

ຫົວໜ້າກວດ ລົດ/ຄົນຂັບ/ນ້ຳໜັກ. ຜ່ານ ➔ ລໍຮັບຖ້ຽວ · ບໍ່ຜ່ານ ➔ ຕີກັບພ້ອມລະບຸເຫດຜົນ (SLA < 2 ຊົ່ວໂມງ).

📦 ຈຸດຕັດສິນ 2: ຜົນການຈັດສົ່ງ (ຂັ້ນ 9)

ສົ່ງຄົບ 100% ➔ ຖ່າຍຮູບ + ລາຍເຊັນ · ສົ່ງບໍ່ຄົບ/ຄືນ ➔ ໃສ່ເຫດຜົນ ➔ ຈັດຮອບຕໍ່ໄປ.

🔄 ກໍລະນີພິເສດ: ທະຍອຍສົ່ງ (Partial Delivery)

ຖ້າສົ່ງໄດ້ບາງສ່ວນ (ຍອດເຫຼືອ > 0) ➔ ລະບົບປ່ຽນເປັນ "ທະຍອຍສົ່ງ" ອັດຕະໂນມັດ ແລະ ດຶງບິນກັບ ລໍຖ້າຈັດຖ້ຽວ ເພື່ອໃຫ້ Office ຈັດຖ້ຽວຮອບຕໍ່ໄປ.

🏢 ກໍລະນີພິເສດ: ສົ່ງຕໍ່ສາຂາ (Branch Forwarding)

ຂົນສົ່ງມອບໃຫ້ສາຂາປາຍທາງ ➔ ສະຖານະເປັນ "ສົ່ງຕໍ່ສາຂາແລ້ວ" ➔ Push Alert ຫາພະນັກງານສາຂານັ້ນ ➔ ບິນເຂົ້າຄິວ ລໍຖ້າຈັດຖ້ຽວ ຂອງສາຂາປາຍທາງ.

⭐ 10 ກໍລະນີການເຮັດວຽກພິເສດ (Special Cases)

1. ທະຍອຍສົ່ງ (Partial Delivery)
ສົ່ງໄດ້ບາງສ່ວນ, ມີຍອດເຫຼືອສິນຄ້າ > 0 ➔ ຄົນຂັບປ້ອນຈຳນວນສົ່ງໄດ້ຈິງ ➔ ລະບົບປ່ຽນສະຖານະເປັນ "ທະຍອຍສົ່ງ" ອັດຕະໂນມັດ ແລະ ດຶງບິນກັບເຂົ້າ ລໍຖ້າຈັດຖ້ຽວ ເພື່ອໃຫ້ Office ຈັດຖ້ຽວຮອບຕໍ່ໄປ.
2. ສົ່ງຕໍ່ສາຂາ (Branch Forwarding)
ຂົນສົ່ງສິນຄ້າໄປມອບໃຫ້ສາຂາປາຍທາງ ➔ ຄົນຂັບກົດ "ສົ່ງຕໍ່ສາຂາ" ➔ ສະຖານະເປັນ forward_transport_code ➔ ລະບົບສົ່ງ Push Alert ຫາສາຂາປາຍທາງ ແລະ ດຶງບິນເຂົ້າຄິວ ລໍຖ້າຈັດຖ້ຽວ ຂອງສາຂານັ້ນອັດຕະໂນມັດ.
3. ແຍກບິນຕາມສາຂາ (Split Bill by Branch)
ບິນ 1 ໃບທີ່ມີສິນຄ້າສົ່ງຫຼາຍສາຂາ ➔ Office ໃຊ້ Dialog "ແຍກບິນຕາມສາຂາ" (WI-A4) ເພື່ອແບ່ງລາຍການສິນຄ້າອອກເປັນບິນຍ່ອຍແຍກຕາມສາຂາປາຍທາງ.
4. ຍ້ອນກັບ / ແກ້ໄຂການສົ່ງຜິດ (Revert / Edit Delivery)
ຖ້າຄົນຂັບກົດສົ່ງຜິດ ຫຼື Office ກວດເຫັນຮູບ/ຈຳນວນບໍ່ຖືກ ➔ Office ໃຊ້ປຸ່ມ "ຍ້ອນກັບ (Revert)" ຫຼື "ແກ້ໄຂ (Edit)" (WI-A3/WI-C7) ເພື່ອປັບຂໍ້ມູນ ຫຼື ຍ້ອນສະຖານະໃຫ້ຄົນຂັບສົ່ງໃໝ່.
5. ເພີ່ມບິນເຂົ້າໃບງານເດີມ (Add Bills to Job)
ມີບິນດ່ວນດຶງເຂົ້າມາຕື່ມ ➔ Office ເປີດໜ້າໃບງານ ➔ ກົດ Dialog "ເພີ່ມບິນເຂົ້າໃບງານ" ດຶງບິນໃໝ່ເຂົ້າໃບງານເດີມໄດ້ໂດຍບໍ່ຕ້ອງສ້າງໃບງານໃໝ່.
6. ປັກໝຸດ/ແກ້ໄຂຕຳແໜ່ງຈັດສົ່ງ (Edit Location / Pin Map)
ບິນບໍ່ມີພິກັດ Lat/Lng ➔ Office ໃຊ້ Dialog "ແກ້ໄຂຕຳແໜ່ງ" (WI-A5) ເພື່ອປັກໝຸດເທິງແຜນທີ່ Google Maps, ຄົນຂັບຈະເຫັນແຜນທີ່ນຳທາງໄດ້ທັນທີ.
7. ກຳນົດວັນ/ຮອບຈັດສົ່ງໃໝ່ (Reschedule Date & Round)
ລູກຄ້າຂໍເລື່ອນວັນຈັດສົ່ງ ➔ ຝ່າຍຂາຍ ຫຼື Office ໃຊ້ Dialog "ກຳນົດວັນຈັດສົ່ງ" ເພື່ອຍ້າຍວັນ ແລະ ຮອບຈັດສົ່ງໄປວັນໃໝ່.
8. ບັນທຶກເຕີມນ້ຳມັນ (Fuel Entry)
ຄົນຂັບເຕີມນ້ຳມັນ ➔ ເປີດແອັບ ➔ ປ້ອນ ເງິນ, ລິດ, ເລກກິໂລແມັດ + ຖ່າຍຮູບໃບບິນ (WI-C6) ➔ Office ກວດອະນຸມັດໃນໜ້າ *ນ້ຳມັນ*.
9. ຕິດຕໍ່ WhatsApp & ຕິດຕາມສາທາລະນະ (/track & /rate)
ກົດ WhatsApp Link ຢູ່ໜ້າບິນ ເພື່ອສົ່ງ Link ຕິດຕາມ /track ຫາລູກຄ້າ. ເມື່ອໄດ້ຮັບສິນຄ້າ ລູກຄ້າສາມາດໃຫ້ຄະແນນ 1-5 ດາວໄດ້ຢູ່ /rate.
10. ແກ້ໄຂ GPS Offline & Session Expired 8h
ຖ້າ GPS ບໍ່ອັບເດດ: ໃຫ້ເປີດ Location Permission Allow all the time + ປິດ Battery Optimization. ຖ້າ Session ໝົດ (8h) ໃຫ້ Re-login ເພື່ອຮັບ Token ໃໝ່.
03

SOP — ລະບຽບການປະຕິບັດງານ (Standard Operating Procedures)

ມາດຕະຖານການປະຕິບັດງານ 5 ບົດບາດ ເພື່ອໃຫ້ການເຮັດວຽກຖືກຕ້ອງ, ທັນເວລາ ແລະ ກວດສອບໄດ້.

Office / Dispatch

SOP-1 · ຈັດຖ້ຽວ & ໃບງານ
  1. ຕົ້ນວັນ: ກວດໜ້າ ລໍຖ້າຈັດຖ້ຽວ ທັງໝົດ.
  2. ຈັດຖ້ຽວ: ກຳນົດ ວັນ/ຮອບ/ເສັ້ນທາງ, ຈັດບິນທາງດຽວກັນເຂົ້າໃບງານດຽວ.
  3. ສ້າງໃບງານ: ຈັບຄູ່ ລົດ + ຄົນຂັບ ໃຫ້ເໝາະກັບນ້ຳໜັກບັນຈຸ.
  4. ສົ່ງອະນຸມັດ: ກວດຄວາມຖືກຕ້ອງ ➔ ສົ່ງໃຫ້ຫົວໜ້າ.
  5. ຕິດຕາມ: ເຝົ້າເບິ່ງບິນຄ້າງ + ຕິດຕາມ GPS ຕະຫຼອດວັນ.
  6. ກວດຮັບ: ກວດຫຼັກຖານການສົ່ງ ➔ ປິດສຳເລັດ.
ກົດລະບຽບ (MUST): ຫ້າມສ້າງໃບງານທີ່ນ້ຳໜັກເກີນລົດ · ທຸກການຍົກເລີກບິນຕ້ອງມີເຫດຜົນ+ອະນຸມັດ.

ຫົວໜ້າ / ຜູ້ຄຸມ (Supervisor)

SOP-2 · ອະນຸມັດ & ຕິດຕາມ KPI
  1. ອະນຸມັດໃບງານ: ກວດ ລົດ/ຄົນຂັບ/ນ້ຳໜັກ ພາຍໃນ SLA < 2h.
  2. ຕິດຕາມ Realtime: ເບິ່ງແຜນທີ່ລົດ ແລະ ຕຳແໜ່ງຄົນຂັບ.
  3. ຕິດຕາມ KPI: ກວດລາຍງານປະຈຳວັນ, ຄ້າງສົ່ງ, Leaderboard.
  4. ຈັດການເຫດການ: ແກ້ໄຂບິນຄ້າງນານ / ຫຼຸດເສັ້ນທາງ.
  5. ພິຈາລະນາ: ອະນຸຍາດຄຳຂໍຍົກເລີກ ຫຼື ແກ້ໄຂບິນ.
ກົດລະບຽບ (MUST): ບໍ່ອະນຸມັດໃບງານທີ່ຂໍ້ມູນບໍ່ຄົບ · ຕີກັບຕ້ອງລະບຸເຫດຜົນຊັດເຈນ.

ຄົນຂັບລົດ (Driver)

SOP-3 · ຮັບ – ຈັດສົ່ງ ຕໍ່ຖ້ຽວ
  1. ກ່ອນອອກງານ: Login, ເປີດ GPS Always + Notifications.
  2. ຮັບຖ້ຽວ & ເບີກ: ຮັບໃບງານ ➔ ເບີກເຄື່ອງຢູ່ສາງ (ກວດຈຳນວນ).
  3. ເລີ່ມຈັດສົ່ງ: ກົດເລີ່ມຈັດສົ່ງ ➔ ເຊັກອິນເມື່ອຮອດຈຸດ.
  4. ຫຼັກຖານການສົ່ງ: ຖ່າຍຮູບສິນຄ້າ/ລາຍເຊັນ ➔ ກົດສົ່ງສຳເລັດ.
  5. ສົ່ງບໍ່ໄດ້: ກົດສົ່ງຄືນ + ໃສ່ເຫດຜົນ + ຮູບ.
  6. ນ້ຳມັນ & ປິດງານ: ບັນທຶກນ້ຳມັນ ➔ ກົດປິດງານ.
ກົດລະບຽບ (MUST): ຫ້າມກົດສົ່ງສຳເລັດໂດຍບໍ່ມີຮູບ · ຫ້າມປິດ GPS ຂະນະຈັດສົ່ງ.

ຝ່າຍຂາຍ (Sales)

SOP-4 · ຕິດຕາມລູກຄ້າ & ວັນຈັດສົ່ງ
  1. ຕິດຕາມ: ເບິ່ງ ບິນສົ່ງບໍ່ສຳເລັດ ຂອງລູກຄ້າຕົນ.
  2. ກຳນົດວັນ: ປະສານ Office ຍ້າຍວັນ/ຮອບຈັດສົ່ງ.
  3. ຢືນຢັນ: ຕິດຕາມຄຳຕິຊົມ ແລະ ຄະແນນ 1-5 ດາວ.
ໝາຍເຫດ: ບັນຊີຝ່າຍຂາຍຖືກຈຳກັດຂອບເຂດຂໍ້ມູນສະເພາະສາຍຂາຍຕົນເອງ.

ຜູ້ດູແລລະບົບ (Admin)

SOP-5 · Master Data & System Admin
  1. Master Data: ຮັກສາຂໍ້ມູນ ລົດ, ພະນັກງານ, ເສັ້ນທາງ, ຮອບ.
  2. Access Control: ກຳນົດສິດ 5 Roles ໃຫ້ຖືກຕ້ອງ.
  3. Audit Log: ກວດ Activity Log ເປັນປະຈຳ.
  4. Security: ຮັບປະກັນ Database Backup ແລະ System Security.
ກົດລະບຽບ (MUST): ຫ້າມໃຫ້ສິດ Admin ແກ່ຜູ້ບໍ່ກ່ຽວຂ້ອງ · ກວດ Audit Log ເປັນປະຈຳ.
04

WI — ຄຳແນະນຳການເຮັດວຽກ 1-2-3 (Work Instructions)

ບັດຂັ້ນຕອນການເຮັດວຽກ 1-2-3 ແຍກຕາມແຕ່ລະວຽກ (Work Instruction Cards).

WI-A1

ຈັດຖ້ຽວບິນ

  1. ເປີດ ຂົນສົ່ງ › ລໍຖ້າຈັດຖ້ຽວ
  2. ໝາຍເລືອກບິນ (ໄດ້ຫຼາຍໃບ)
  3. ກຳນົດ ວັນ · ຮອບ · ເສັ້ນທາງ
  4. ບັນທຶກ ➔ ບິນ ໄປ ບິນລໍຕາມເສັ້ນທາງ
WI-A2

ສ້າງໃບງານ

  1. ເປີດ ບິນລໍຕາມເສັ້ນທາງ
  2. ເລືອກກຸ່ມ ➔ ກົດ ສ້າງໃບງານ
  3. ເລືອກ ລົດ + ຄົນຂັບ (ກວດນ້ຳໜັກ)
  4. ກົດ ສົ່ງອະນຸມັດ
WI-A3

ກວດຮັບ & ປິດງານ

  1. ເປີດ ຄົນຂັບປິດງານ
  2. ກວດຮູບ + ຈຳນວນ ຕໍ່ບິນ
  3. ຄົບ ➔ ກົດ ປິດສຳເລັດ
  4. ຂາດ/ຜິດ ➔ ກົດ ຕີກັບ (Revert)
WI-A4

ແຍກບິນຕາມສາຂາ

  1. ຢູ່ໜ້າ ລໍຖ້າຈັດຖ້ຽວ
  2. ເລືອກບິນ ➔ ກົດ ແຍກບິນຕາມສາຂາ
  3. ເລືອກລາຍການ ➔ ລະບຸສາຂາປາຍທາງ
  4. ບັນທຶກ ➔ ໄດ້ບິນຍ່ອຍແຍກສາຂາ
WI-A5

ປັກໝຸດແຜນທີ່ (Pin Map)

  1. ຖ້າບິນບໍ່ມີພິກັດ Lat/Lng
  2. ກົດ ແກ້ໄຂຕຳແໜ່ງ ຢູ່ໜ້າບິນ
  3. ຄົ້ນຫາ/ຍ້າຍໝຸດ ➔ ບັນທຶກ
WI-B1

ອະນຸມັດ / ຕີກັບ

  1. ເປີດ ອະນຸມັດ › ລໍອະນຸມັດ
  2. ກວດ ລົດ/ຄົນຂັບ/ນ້ຳໜັກ/ເສັ້ນທາງ
  3. ຖືກ ➔ ກົດ ອະນຸມັດ
  4. ຜິດ ➔ ກົດ ຕີກັບ + ໃສ່ເຫດຜົນ
WI-C1..3

ຄົນຂັບ: ຮັບ ➔ ສົ່ງ

  1. ກົດ ຮັບຖ້ຽວ ➔ ເບີກເຄື່ອງຢູ່ສາງ
  2. ກົດ ເລີ່ມຈັດສົ່ງ (GPS ເປີດຕະຫຼອດ)
  3. ຮອດຈຸດ ➔ ກົດ ເຊັກອິນ
  4. ມອບ ➔ ຖ່າຍຮູບ ➔ ກົດ ສົ່ງສຳເລັດ
WI-C4..6

ຄົນຂັບ: ບໍ່ຄົບ & ນ້ຳມັນ

  1. ສົ່ງບໍ່ໄດ້ ➔ ກົດ ສົ່ງຄືນ + ເຫດຜົນ
  2. ເຕີມນ້ຳມັນ ➔ ປ້ອນເງິນ/ລິດ + ຖ່າຍໃບບິນ
  3. ຈົບ ➔ ກົດ ປິດງານ
WI-D1

ຝ່າຍຂາຍ: ຕິດຕາມບິນ

  1. ເປີດ ຕິດຕາມ › ບິນສົ່ງບໍ່ສຳເລັດ
  2. ຄົ້ນຫາຕາມລູກຄ້າ / ເລກບິນ
  3. ກຳນົດວັນຈັດສົ່ງ (ປະສານ Office)
05

FAQ & Troubleshooting — ຄຳຖາມທີ່ພົບເລື້ອຍ ແລະ ວິທີແກ້ໄຂ

ວິທີແກ້ໄຂບັນຫາທີ່ພົບເລື້ອຍໃນການປະຕິບັດງານປະຈຳວັນ.

⚠️ ຄົນຂັບກົດ "ສົ່ງບິນສຳເລັດ" ບໍ່ໄດ້ ເຮັດແນວໃດ?
1. ກວດສັນຍານອິນເຕີເນັດ handheld/ມືຖື.
2. ຖ້າ Session ໝົດອາຍຸ (ຫຼຸດ 8h) ➔ ໃຫ້ Logout ແລ້ວ Login ໃໝ່.
3. ຖ້າຮູບໃຫຍ່ເກີນ 8MB ➔ ໃຫ້ຫຼຸດຄວາມລະອຽດກ້ອງມືຖື ຫຼື ຖ່າຍໃໝ່.
⚠️ ຕຳແໜ່ງ GPS ລົດບໍ່ອັບເດດ ເທິງແຜນທີ່?
1. ເປີດ Settings ມືຖືຄົນຂັບ ➔ Location Permissions ➔ ເລືອກ "Allow all the time".
2. ປິດ Battery Saver Mode / Battery Optimization ຂອງແອັບ.
3. ຖ້າໃຊ້ GPS Hardware ➔ ກວດສອບກ່ອງ GPS ເທິງລົດ ແລະ ສັນຍານ SIM.
⚠️ ກົດສົ່ງບິນຜັດ ຫຼື ປ້ອນຈຳນວນຜິດ ຢາກຍ້ອນກັບແກ້ໄຂ?
Office ຢູ່ໜ້າ ຄົນຂັບປິດງານ ສາມາດກົດປຸ່ມ "ຍ້ອນກັບ (Revert)" ເພື່ອສົ່ງບິນກັບໄປໃຫ້ຄົນຂັບແກ້ໄຂໃໝ່ໄດ້ ກ່ອນທີ່ຈະກົດ ປິດສຳເລັດ.
