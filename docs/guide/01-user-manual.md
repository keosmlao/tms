# ຄູ່ມືການໃຊ້ງານ ODG TMS (User Manual)

ເອກະສານນີ້ອະທິບາຍ **ທຸກໜ້າ / ທຸກເມນູ** ຂອງລະບົບ ວ່າໃຊ້ເຮັດຫຍັງ ແລະ ໃຊ້ແນວໃດ.

---

## 1. ການເຂົ້າສູ່ລະບົບ (Login)

### 1.1 Web Dashboard (ຄອມພິວເຕີ)
1. ເປີດ browser ໄປທີ່ URL ຂອງລະບົບ (ເຊັ່ນ `https://tms.odien.net`).
2. ປ້ອນ **ຊື່ຜູ້ໃຊ້** ແລະ **ລະຫັດຜ່ານ** (ໃຊ້ບັນຊີ ERP ເດີມ).
3. ກົດ **ເຂົ້າສູ່ລະບົບ**.
4. ຖ້າຊື່ຜູ້ໃຊ້/ລະຫັດຜ່ານບໍ່ຖືກ ຈະຂຶ້ນຂໍ້ຄວາມ *"ຊື່ຜູ້ໃຊ້ ຫຼື ລະຫັດຜ່ານບໍ່ຖືກຕ້ອງ"*.

> ໝາຍເຫດ: ລະບົບຈຳກັດການ login ບໍ່ເກີນ **10 ຄັ້ງ/ນາທີ** ຕໍ່ 1 IP ເພື່ອຄວາມປອດໄພ. ຖ້າຖືກຈຳກັດ ໃຫ້ລໍ 1 ນາທີ ແລ້ວລອງໃໝ່.

### 1.2 ແອັບຄົນຂັບ (ມືຖື)
- ຄົນຂັບ login ດ້ວຍຊື່ຜູ້ໃຊ້/ລະຫັດຜ່ານດຽວກັນ. ລະບົບຈະໃຫ້ token ໃຊ້ໄດ້ 8 ຊົ່ວໂມງ ແລ້ວຕໍ່ອາຍຸ (refresh) ອັດຕະໂນມັດ.
- ຄັ້ງທຳອິດ ອະນຸຍາດສິດ **ຕຳແໜ່ງ (Location)** ແລະ **ການແຈ້ງເຕືອນ (Notification)** ໃຫ້ຄົບ ບໍ່ດັ່ງນັ້ນ GPS ແລະ ການແຈ້ງເຕືອນຈະບໍ່ເຮັດວຽກ.

### 1.3 ສິດການໃຊ້ງານ (Roles)
| ບົດບາດ | ໃຊ້ຫຍັງ |
|--------|---------|
| **office / dispatch** | ຈັດຖ້ຽວ, ສ້າງໃບງານ, ຕິດຕາມ, ອອກລາຍງານ, ຈັດການຂໍ້ມູນພື້ນຖານ |
| **ຫົວໜ້າ / ຜູ້ຄຸມ (manager/head)** | ອະນຸມັດ, ຕິດຕາມ KPI, ເບິ່ງລາຍງານ, ຄຸມພາບລວມ |
| **ຝ່າຍຂາຍ (sales)** | ເບິ່ງສະເພາະ *ບິນສົ່ງບໍ່ສຳເລັດ*, *ກຳນົດວັນຈັດສົ່ງ*, *ບິນສົ່ງສຳເລັດ* (ຖືກຈຳກັດຂອບເຂດ) |
| **ຄົນຂັບ (driver)** | ຮັບຖ້ຽວ, ເບີກເຄື່ອງ, ຈັດສົ່ງ, ຖ່າຍຮູບຫຼັກຖານ, ບັນທຶກນ້ຳມັນ (ຜ່ານແອັບມືຖື) |

## 2. ໜ້າຫຼັກ (Dashboard)
ຫຼັງ login ຈະເຫັນໜ້າພາບລວມ: ຈຳນວນບິນໃນແຕ່ລະສະຖານະ, ໃບງານທີ່ກຳລັງແລ່ນ, ການແຈ້ງເຕືອນ. ໃຊ້ເປັນຈຸດເລີ່ມຕົ້ນເບິ່ງວ່າມີວຽກຄ້າງບ່ອນໃດ.

**ແຖບເມນູດ້ານຊ້າຍ (Sidebar)** ແບ່ງເປັນ 7 ໝວດ: ຕິດຕາມ · ອະນຸມັດ · ຂົນສົ່ງ · ລາຍງານ · ນ້ຳມັນ · ທັນໃຈ Express · ການຈັດການ. ນອກນັ້ນມີ ປະຕິທິນຈັດສົ່ງ ແລະ ກ່ອງຂໍ້ຄວາມ (Inbox) ຢູ່ແຖບເທິງ.

## 4. ໝວດ "ອະນຸມັດ"
- **ລໍອະນຸມັດ** — ໃບງານທີ່ລໍການອະນຸມັດ. ຫົວໜ້າກວດແລ້ວກົດ **ອະນຸມັດ** ຫຼື **ຕີກັບ**.
- **ອະນຸມັດແລ້ວ** — ລາຍການທີ່ອະນຸມັດຜ່ານແລ້ວ ພ້ອມ **ລາຍງານ** ສະຫຼຸບ.

## 6. ໝວດ "ລາຍງານ" (Reports)
ລາຍງານມີໃຫ້ຫຼາຍມຸມ — ເລືອກຊ່ວງວັນທີແລ້ວກົດ **ຄົ້ນຫາ/ສ້າງລາຍງານ**, ສ່ວນຫຼາຍ export ເປັນ Excel ໄດ້.

- **ປະຈຳວັນ / ເຄື່ອນໄຫວ (ບິນ) / ເຄື່ອນໄຫວ (ສິນຄ້າ)** — ພາບລວມກິດຈະກຳຕໍ່ວັນ.
- **ບິນຄ້າງສົ່ງ/ວັນ · ສົ່ງສຳເລັດ/ວັນ · ຍົກເລີກ/ວັນ** — ຈຳນວນຕາມສະຖານະຕໍ່ວັນ.
- **ຕາມຄົນຂັບ · ຕາມລົດ · ຕາມບິນ** — ວິເຄາະລົງລາຍລະອຽດ.
- **ນຳໃຊ້ລົດ/ເດືອນ · ຄົນຂັບ/ເດືອນ** — ສະຫຼຸບປະຈຳເດືອນ.
- **Leaderboard ຄົນຂັບ** — ຈັດອັນດັບຜົນງານຄົນຂັບ.

## 7. ໝວດ "ນ້ຳມັນ"
- **ບັນທຶກເຕີມນ້ຳມັນ** — ບັນທຶກ/ກວດປະຫວັດການເຕີມນ້ຳມັນ. ຄົນຂັບບັນທຶກຈາກແອັບ (ໃສ່ຈຳນວນເງິນ/ລິດ + ຮູບໃບບິນ), office ກວດ ແລະ ສະຫຼຸບຢູ່ໜ້ານີ້.

## 10. ໜ້າຕິດຕາມສາທາລະນະ (Public Tracking)
- ລູກຄ້າ (ຫຼື ໃຜກໍໄດ້) ເປີດໄດ້ທີ່ `/track` ໂດຍບໍ່ຕ້ອງ login — ໃສ່ເລກບິນເພື່ອເບິ່ງສະຖານະ.
- ໜ້າ `/rate` ໃຊ້ໃຫ້ຄະແນນ/ຄຳຕິຊົມການບໍລິການ.
- ຈຳກັດ 60 ຄັ້ງ/ນາທີ ຕໍ່ IP.

## 11. ແອັບຄົນຂັບ (ໂດຍຫຍໍ້)
ຄົນຂັບເຮັດວຽກຜ່ານມືຖືທັງໝົດ: ຮັບຖ້ຽວ → ເບີກເຄື່ອງ → ເລີ່ມຈັດສົ່ງ → ເຊັກອິນຕາມຈຸດ → ຖ່າຍຮູບຫຼັກຖານ → ສົ່ງສຳເລັດ/ສົ່ງຄືນ → ປິດງານ, ພ້ອມສົ່ງ GPS ອັດຕະໂນມັດ ແລະ ບັນທຶກເຕີມນ້ຳມັນ. ລາຍລະອຽດຂັ້ນຕອນຢູ່ [WI ພາກຄົນຂັບ](04-work-instructions.md#wi-c-ຄົນຂັບລົດ).
